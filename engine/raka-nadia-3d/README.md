Mesin render "Raka & Nadia" (3D kartun, Three.js + overlay kanvas 2D).
three.module.js (r160) diunduh dari cdn.jsdelivr.net/npm/three@0.160.0/build/three.module.js ke folder ini.
Jalankan: python3 -m http.server 8766, lalu node worker.mjs <k> <jumlahWorker> <totalFrame> <outDir> (24 fps),
gabung dengan ffmpeg + audio (narasi-bagian01.mp3, musik dari music1.py).
